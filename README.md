## What I've built

### [Qorasp](https://qorasp.com): school management software

Replaces the paper register, the fees receipt book and hand-written report cards. It covers phone-based
attendance, school and feeding fees with instant receipts, printable terminal reports, timetables,
promotions, a school bookstore and SMS fee alerts, across seven role-based portals. Each school gets
its own address (yourschool.qorasp.com).

`Node.js` `Express` `PostgreSQL` `JavaScript` `nginx` `Cloudflare` · about 350 automated tests · staging site and nightly backups

### [QwikTill](https://qwiktill.com): point of sale for shops

The till, stock book and sales report in one app. It offers cash and MoMo checkout, barcode scanning,
offline sales that sync when the connection returns, stock across branches with low-stock alerts, and
printable profit reports.

`TypeScript` `React` `Node.js` `Prisma` `PostgreSQL` · integration tests · GitHub Actions CI

Both products are live. I handle everything from database design and APIs to deployment, servers and
support. Their code lives in private repositories, and I'm happy to walk through it. New open-source
projects are on the way here.
